# Procedural Approach

This folder contains beginner-level Python files written in a step-by-step procedural style.

The goal is to build logic without focusing on functions or classes first.

## Topics

1. Variables
2. Data types
3. Operators
4. Input and output
5. If-else statements
6. Loops
7. Strings
8. Lists
9. Dictionaries
10. Basic problem solving

## Learning Focus

Write simple code first. Understand the flow. Do not jump into advanced syntax before your basic logic is clear.
