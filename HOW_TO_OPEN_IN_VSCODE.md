# How to Open This Repository in VS Code

GitHub opens files in the browser by default. That is normal.

To open this repository in VS Code properly, use one of these methods.

---

## Method 1: Clone and Open in VS Code

```bash
git clone https://github.com/jarjishkhan695-blip/MY_PYTHON_JOURNEY.git
cd MY_PYTHON_JOURNEY
code .
```

---

## Method 2: Open the Workspace File

After cloning the repository, run:

```bash
code python_journey.code-workspace
```

---

## Method 3: Open in Browser-Based VS Code

Open the repository on GitHub and press:

```text
.
```

This opens the repository in `github.dev`, which looks like VS Code inside the browser.

---

## Important Truth

A file on GitHub will not automatically open in your local VS Code just by clicking it. You need to clone the repo first or use `github.dev`.
