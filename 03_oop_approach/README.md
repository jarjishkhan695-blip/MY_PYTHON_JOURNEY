# Object-Oriented Programming Approach

This folder contains Python files focused on object-oriented programming.

The goal is to learn how to organize code using classes, objects, attributes, and methods.

## Topics

1. Classes and objects
2. Constructor
3. Instance variables
4. Class variables
5. Inheritance
6. Encapsulation
7. Polymorphism
8. OOP-based problem solving

## Learning Focus

OOP is useful when your program has real entities with data and behavior. Do not use classes blindly. Use them when they make the code easier to organize.
