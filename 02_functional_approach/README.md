# Functional Approach

This folder contains Python files focused on reusable logic using functions.

The goal is to move from repeated step-by-step code to cleaner function-based code.

## Topics

1. Basic functions
2. Parameters and arguments
3. Return vs print
4. Lambda functions
5. map, filter, and reduce
6. Recursion
7. Function-based problem solving

## Learning Focus

Do not write the same logic again and again. Put reusable logic inside functions and return values when you need to use results later.
