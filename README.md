# My Python Journey

This repository documents my Python learning journey in a structured way.

Instead of mixing random programs, the repository is divided into three programming approaches:

1. **Procedural Approach**
2. **Functional Approach**
3. **Object-Oriented Programming Approach**

The goal is to understand how Python code evolves from simple step-by-step logic into reusable functions and then into organized object-oriented code.

---

## 1. Procedural Approach

This section focuses on beginner-level Python logic where code is written step by step.

Topics covered:

- Variables
- Data types
- Operators
- Input and output
- Conditional statements
- Loops
- Strings
- Lists
- Dictionaries
- Basic problem solving

---

## 2. Functional Approach

This section focuses on writing reusable logic using functions.

Topics covered:

- Basic functions
- Parameters and arguments
- Return vs print
- Lambda functions
- `map()`, `filter()`, and `reduce()`
- Recursion
- Function-based problem solving

---

## 3. Object-Oriented Programming Approach

This section focuses on organizing code using classes and objects.

Topics covered:

- Classes and objects
- Constructors
- Instance variables
- Class variables
- Inheritance
- Encapsulation
- Polymorphism
- OOP-based problem solving

---

## Purpose

This repository is not just a dump of Python files. It is designed to show a clear learning path:

```text
Procedural Programming → Functional Programming → Object-Oriented Programming
```

That progression matters because it shows how basic logic can become cleaner, reusable, and more professional over time.
